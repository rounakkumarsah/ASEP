# Security Policy

## Supported Versions

Only the latest major version of ASEP is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of ASEP seriously. If you discover a security vulnerability in this project, please report it immediately.

### How to Report
Please email your findings to **security@asep.local**. Do not open a public issue on GitHub for security vulnerabilities.

### What to Include
* A detailed description of the vulnerability.
* Steps to reproduce the issue.
* The version of ASEP affected.
* Any potential impact or risk assessment.

### Response SLA
* **Acknowledgment:** Within 24 hours.
* **Triage & Assessment:** Within 48 hours.
* **Patch Development (Critical/High):** Within 7 days.

### Safe Harbor
We strongly support good-faith security research. We will not take legal action against researchers who disclose vulnerabilities to us privately and give us a reasonable timeframe to patch before public disclosure.
