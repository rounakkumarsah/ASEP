## 3. Key Differentiators & Competitive Moat

1. **Deterministic LangGraph DAG:** Prevents uncontrolled ReAct agent loops by enforcing strict step boundaries (3–10 subtasks).
2. **Hardened Non-Root Container Sandboxes:** Eliminates container breakout risks by stripping all Linux kernel capabilities and enforcing non-executable tmpfs.
3. **4-Tier Hybrid Memory:** Outperforms flat vector search by fusing chronological episodic history, dense vectors, and Neo4j AST knowledge graphs.
4. **Sovereign Local LLM Execution:** First-class native support for Ollama / vLLM allows 100% air-gapped operation with zero data transmission to cloud APIs.
5. **Clean IP Provenance:** Sole-author ownership with zero contractor claims, zero corporate liens, and clean MIT licensing.
